StorageLens 1.0.0 focuses on making item tracking more reliable in real
SkyBlock mod setups. This release fixes a few bugs found while using
StorageLens alongside SkyHUD and other inventory-screen replacements.

### What changed

- Fixed Ender Chest, backpack, Loadout, Wardrobe, and Equipment observations
  being missed when another mod replaces the visible container screen.
- Fixed equipped armor from the active Wardrobe slot being counted as a second
  owned armor set.
- Improved local storage observations and regression coverage across both
  supported Minecraft versions.

Thanks for testing StorageLens and reporting the rough edges.
