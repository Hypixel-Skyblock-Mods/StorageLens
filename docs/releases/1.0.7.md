StorageLens 1.0.7 supports Fabric on Minecraft 26.1.2, 26.2 and 26.3.

- Add a dedicated 26.3 target with the new RenderPearl texture types and SDL keyboard backend while retaining shared behavior across all targets.
- Bundle the official MoulConfig 26.3 source port from pinned revision 4eaeb73cdaeb, with verified source download, reproducible builds, distinct keyboard/mouse bindings and correct Fabric access-widener discovery.
- Preserve existing search bindings when upgrading from GLFW to SDL by storing stable key names and migrating legacy numeric values.
- Keep release jobs on GitHub-hosted Ubuntu; install JDK 8 for MoulConfig common sources and JDK 25 for Minecraft builds.

Validation: full three-target builds and existing JUnit tests; separate Fabric smoke runs for each version verify production mixin application, MoulConfig linkage and rendering pipeline initialization. Gameplay on a live Hypixel server was not tested.
