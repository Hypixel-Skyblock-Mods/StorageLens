StorageLens 1.0.1 fixes the Item Search keybind opening while another screen is
already in use.

### What changed

- The Item Search keybind now works only during normal gameplay.
- Inventories, container screens, signs, chat, and modded search fields no
  longer trigger StorageLens while typing or interacting with them.
- The `/storagelens search` command remains available for deliberate access.
