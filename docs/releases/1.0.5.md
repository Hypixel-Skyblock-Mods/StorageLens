StorageLens 1.0.5 fixes storage refreshes and duplicate armor ownership in Item Search.

### What changed

- Opening an Ender Chest, backpack, or other supported storage now replaces its
  cached contents, including when another mod displays a custom container
  overlay.
- Empty slots are recorded during refreshes so removed items no longer remain
  in search results.
- Equipment and wardrobe references remain searchable but no longer increase
  owned item counts or estimated value.
- Equipped armor and its matching wardrobe entry are treated as the same item,
  while genuinely separate copies still count separately.
- Removed the stale-data `!` marker from item locations.
